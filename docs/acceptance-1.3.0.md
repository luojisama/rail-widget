# v1.3.0 验收

## 安装

在本次 PR 的 Actions 中下载 `RailCard-1.3.0-APK`，解压安装 APK。
这是 Debug 验收包；只有签名一致时才能覆盖安装旧版。需要卸载时请先保留原行程数据。
不发布正式 Release，验收后再决定合并与正式签名发布。

## MIUI 14 / Android 13

1. 打开设置中的灵动岛自动化，允许精确闹钟、通知、悬浮窗。
2. 在 MIUI 权限页允许自启动与后台弹出，将省电策略设为无限制。
3. 添加一个即将进入提前唤起窗口的行程，退出应用并锁屏，核对窗口开始时是否出现灵动岛。
4. 修改提前时间、删除行程、关闭自动化，确认旧闹钟不会唤起错误车次。
5. 重启手机后解锁，核对闹钟恢复；撤回再授予精确闹钟权限，核对调度恢复。
6. 手动关闭灵动岛后刷新状态，不应立即重开；手动再次启动应正常工作。
7. 到站后换乘接力；无换乘时保留原有 15 分钟关闭缓冲。

系统强行停止应用会撤销后台执行能力；再次打开应用后恢复。普通清理后台与强行停止需区分记录。

## 状态与资料

- 不配置邮箱也能刷新桌面卡片；应用顶部刷新状态与邮箱同步为独立入口。
- 保持应用打开，观察检票、发车、到站边界，行程分类无需重新导入即可更新。
- 断网点击刷新，本地状态照常更新，保留已有资料，并提示未取得新数据。
- 在跨日、中途上车、多日运行行程中检查当前到站与下一站；无实时数据时显示“按时刻表推算”。
- 检票口和站台独立显示；手动检票口刷新后保留，清空手动值后恢复自动查询。
- 从旧版升级，原行程、归档记录和设置仍在，新资料重启后仍可读取。
- 对照旧版检查配色、字体、圆角、卡片结构；新增资料位于现有展开区域。

## 数据覆盖限制

路路通缓存提供车型交路参考及各站线路里程标。**线路里程标不等于列车累计里程**，跨线运行不能直接相减。
12306 列车详情提供完整的累计距离序列时，显示列车全程及本次乘坐里程；缺失、倒退或无法确定始发里程时显示“暂无”。
12306 列车详情、车型接口用于补充担当局、车型、检票口、站台和餐车信息；字段缺失或接口受限时显示“暂无”。
不以车型猜测餐车，不以检票口推断站台，不使用今日数据覆盖其他日期的车票。
实时到发信息只在最近 5 分钟查询且有明确事件时使用，其余按时刻表推算。
Actions 的 `RailCard-Reports` 包含测试、Lint 及公开数据源冒烟检查结果；接口可访问不代表每个字段都有数据。
